# sobkru — Teacher Exam Tutor App

This repository contains the source code for a **Teacher Exam Tutor** app exported from Google&nbsp;AI&nbsp;Studio. It uses **Vite**, **React** and **TypeScript** to provide an interactive interface that communicates with **Supabase** for app data/storage and the Gemini API for AI-assisted features.

## Getting Started

Follow these steps to set up the project in your IDE and run it locally:

1. **Install dependencies**.  Run the following command in the project root:

   ```bash
   npm install
   ```

2. **Configure environment variables**.  Copy the provided `.env.example` file to `.env.local` and fill in the required values:

   - `GEMINI_API_KEY` — your Gemini API key used to authenticate requests to the Gemini model.
   - `VITE_SUPABASE_URL` — your Supabase project URL.
   - `VITE_SUPABASE_ANON_KEY` — your Supabase anon public key.
   - `VITE_SUPABASE_IMAGES_BUCKET` — image bucket name, default `sobkru-images`.
   - `VITE_SUPABASE_SLIPS_BUCKET` — slip bucket name, default `sobkru-slips`.
   - `VITE_SUPABASE_FILES_BUCKET` — file bucket name, default `sobkru-files`.

   Before running the app against Supabase, open `supabase/schema.sql` and run it in Supabase Dashboard > SQL Editor. This creates all required tables, RPC functions, RLS policies, and Storage buckets.

   Example `.env.local`:

   ```env
   GEMINI_API_KEY=your-gemini-api-key-here
   VITE_SUPABASE_URL=https://your-project-ref.supabase.co
   VITE_SUPABASE_ANON_KEY=your-supabase-anon-public-key
   VITE_SUPABASE_IMAGES_BUCKET=sobkru-images
   VITE_SUPABASE_SLIPS_BUCKET=sobkru-slips
   VITE_SUPABASE_FILES_BUCKET=sobkru-files
   ```

   For Stripe PDF delivery, add the server-only variables in Vercel:

   ```bash
   STRIPE_SECRET_KEY=sk_live_or_test_key
   STRIPE_WEBHOOK_SECRET=whsec_...
   STRIPE_ADMIN_TOKEN=change-this-to-a-long-random-secret
   CRON_SECRET=change-this-to-a-long-random-secret
   ```

   In Stripe Dashboard, add a webhook endpoint pointing to `https://your-domain.com/api/stripe-webhook` and enable `checkout.session.completed` plus `checkout.session.async_payment_succeeded`. The GitHub Actions fallback cron also needs repository secrets `VERCEL_APP_URL` and `CRON_SECRET`.

3. **Run the development server**.  Start the app locally using Vite:

   ```bash
   npm run dev
   ```

   By default the app runs on [`http://localhost:3000`](http://localhost:3000), but Vite will choose another available port if necessary.

## Building for Production

To build an optimized production version of the app, run:

```bash
npm run build
```

The compiled assets will be output to the `dist/` directory.  You can serve those files from any static hosting provider.

## Notes

- This project was generated by Google&nbsp;AI&nbsp;Studio. The original metadata can be found in the `metadata.json` file.
- Supabase setup details are documented in `docs/supabase-setup.md`.
- The `.env.example` file lists all environment variables the app expects.  Never commit your real API keys to version control.
